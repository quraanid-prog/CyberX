# CyberX — Fun Internet Safety

CyberX is a responsive, interactive cybersecurity-awareness website designed as a college project. It teaches safe internet habits using short games and visual activities.

## Features
- Password-strength practice meter (use fake passwords only)
- Interactive phishing red-flag game
- Flip cards explaining common malware types
- Four-question cybersecurity quiz with feedback and score
- Personal safety checklist with a live progress meter
- Incident-response tips and an India cybercrime reporting reference
- Responsive neon design for phones and desktops

## Files
- `index.html` — complete website (HTML, CSS, and JavaScript in one file)
- `requirements.txt` — dependencies (none; this is a static website)
- `Project_Report.pdf` — project documentation

## Run on a phone or computer
1. Keep `index.html` saved in the same folder as the other project files.
2. Open `index.html` in a modern browser. No installation or server is required.
3. If a browser or file manager will not open it directly, upload `index.html` to a static host such as GitHub Pages, Netlify, or Cloudflare Pages.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public repository** named `CyberX`.
2. Upload `index.html`, `README.md`, and optionally `requirements.txt` and `Project_Report.pdf`.
3. In the repository, open **Settings → Pages**.
4. Select deployment from the `main` branch and the root (`/`) folder, then save.
5. Wait for GitHub Pages to publish. The repository's Pages section will show the website URL.
6. Paste the repository URL (not just the website URL, unless your form asks for the live site) into the submission form's **GitHub Repository** field.

## Important notes
- This is an educational demonstration, not a full security product.
- Do not enter real passwords in the password tester.
- No credentials are collected or transmitted by the site.
- The website has no external packages or build step.
